# 原文逐页核查记录

这里保存 2026-10-11 发布整理前的人工核查记录：原标准 72 页，修订后的样书 79 页。原 PDF 内容通过页面图像 OCR 转录，没有读取损坏的正文文字层。

`text-review.json` 与 `visual-review.json` 保留当时的源码及 PDF 哈希；同名 Markdown 提供逐页说明，`code-review.md` 记录当时的模板精简及自动检查。记录中的 `research/`、`output/qa/` 等路径是当时完整工作区的路径，历史中间稿没有纳入公开构建。

发布阶段的字体文件修复、重编哈希、渲染差异和构建结果见 `../publishing.md` 与 `../validation.json`。此目录的历史记录不随每次自动构建覆盖；后续正文修订应重新检查对应原页并记录新哈希。
