## 原生标签与引用迁移

`clause()`、`term()` 不再接收 `key` 参数。默认条目无标签也自动编号和编目；需要正文或索引引用时，在调用后附加原生 `<标签>`，引用统一使用 `@标签`。与原生标题、图表和公式使用同一套标记。紧邻中文或字母时可用 `#[@标签]` 隔开语法边界，不增加可见空格。

样书删去 45 个未使用的无标题条标注；其余 55 个无标题条标签和 17 个术语标签保留实际引用用途。样书 199 处显式引用及图解中的 4 处引用改为原生标记，手册和组件示例同步更新。

编号检查改用独立于标签的完整期望序列，覆盖 296 个编号：179 个有标题章条、100 个无标题条、17 个术语。两字体下的 4 个插入组合、8 个目录组合、标签唯一性、12 个相邻条目、索引及页引用均通过。

两版样书各 79 页，与迁移前逐页规范化文字和 144 dpi 渲染完全一致；内部链接目标页号和坐标也完成对照。手册仍为 10 页，变更代码示例已渲染查看，无越框或意外方括号。详情见 `native-reference-regression.json` 和 `validation.json`。本次是源码及引用回归检查，历史原文人工核查记录保持原哈希。

## 可再生文件与 Git 忽略规则

字体二进制和参考字库、`.tools/`、`output/qa/`、`output/tmp/`、构建报告及源码 ZIP 不提交到 Git。仓库保留字体清单和许可、核查记录、四个正式 PDF，以及 `book/demo-pdf/` 的 32 个矢量示例片段。

新增 `tools/clean.py`，先预览清理范围，再删除可再生文件：

```sh
python tools/clean.py --dry-run
python tools/clean.py
```

清理范围为临时解包副本、QA 预览与测试输出、构建报告、源码 ZIP 和脚本字节码。源码、正式 PDF、示例片段、本地字体和运行依赖保留；需要时重新构建、渲染或打包即可。
